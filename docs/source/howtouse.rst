====================
How to use BlenderNC
====================

BlenderNC has been developed with the goal to simplify the initial steps for the
first time Blender user. If you have never used Blender, please watch the following videos:

- `3D view port  <https://youtu.be/ILqOWe3zAbk>`_
- `Interface  <https://youtu.be/8XyIYRW_2xk>`_
- `Select objects  <https://youtu.be/hTL6AKR8YDs>`_
- `Add objects  <https://youtu.be/JSAobQPRLwc>`_
- `Workspaces  <https://youtu.be/7DNmaR7TKwU>`_


Once you are confident with the basics, then follow the quickstart guide and then the in-depth guide.
