=================
Install BlenderNC
=================

Installing BlenderNC is really simple:


- Go to the `BlenderNC releases page`_ and download the zip file for your operating system or click the links below:

  - **Windows (64-bit):** `blendernc-0.10.0-windows_x64.zip`_
  - **macOS (Apple Silicon, macOS 15 or newer):** `blendernc-0.10.0-macos_arm64.zip`_
  - **Linux (64-bit):** `blendernc-0.10.0-linux_x64.zip`_

  Each zip includes the Python libraries BlenderNC needs for that platform, so
  make sure you pick the one that matches your system.

.. _blendernc-0.10.0-windows_x64.zip: https://github.com/blendernc/blendernc/releases/download/v0.10.0/blendernc-0.10.0-windows_x64.zip
.. _blendernc-0.10.0-macos_arm64.zip: https://github.com/blendernc/blendernc/releases/download/v0.10.0/blendernc-0.10.0-macos_arm64.zip
.. _blendernc-0.10.0-linux_x64.zip: https://github.com/blendernc/blendernc/releases/download/v0.10.0/blendernc-0.10.0-linux_x64.zip
.. _BlenderNC releases page: https://github.com/blendernc/blendernc/releases

- Drag and drop it into Blender:

.. image:: ../videos/install_blendernc.gif
   :width: 100%
   :alt: Install BlenderNC


You can also install it directly in Blender (4.2 or newer) by going to `Edit > Preferences > Get Extensions`, opening the drop-down menu in the top-right corner, choosing `Install from Disk...` and selecting the downloaded zip file. After installation, make sure BlenderNC is enabled in `Edit > Preferences > Add-ons`.
